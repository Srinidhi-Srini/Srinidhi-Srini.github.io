Hello everyone. This post will be the first out of two on Circuit basics. This post will cover Ohm's Law and Equivalent resistance. The next post will be on the Kirchhoff's Current and Loop Laws, equations used to solve various circuit values. First, let's briefly talk about what a circuit is.



## Circuits
A circuit is a closed and unbroken loop of conductive material that allows current to pass through. It's powered by something like a voltage or current source. Voltage (V) is what pushes current throughout the circuit. It's the potential energy difference between two points. Current (I) is the flow of electric charge. Resistance (R) slows down or blocks current from flowing. We can quantify the relationship between these components using Ohm's Law: V=IR.

But, most of the time, circuits aren't as simple as the one above. There may be multiple resistors, paths, currents and voltages we need to find. To make circuits easier to solve, the primary step is combining all the resistors into one resistor source.

## Resistors in Series
Resistors in series are those that are connected end-to-end, and the same current flows through them. 

![R_series circuit](/assets/images/bpp5.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

Here, let's say $$ R_{1} = 5 \Omega$$, $$ R_{2} = 10 \Omega$$ and $$ R_3 = 15 \Omega$$. These 3 resistors are in series, so $$R_{eq} = R_{1} + R_{2} + R_{3}$$, which is 5 + 10 + 15 = 25 $$\Omega$$. We can then rewrite this as a singular resistor with resistance $$ R_{eq} $$. 

## Resistors in Parallel
Resitors in parallel are those connected across the same 2 nodes. A node is a point where two or more circuit elements meet. They have the same voltage, but different current. 

![R_parallel circuit](/assets/images/bpp6.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

Again, let's say $$ R_{1} = 5 \Omega$$, $$ R_{2} = 10 \Omega$$ and $$ R_3 = 15 \Omega$$. These 3 resistors are in parallel, so $$R_{eq} = (\frac{1}{R_{1}} + \frac{1}{R_{2}} + \frac{1}{R_{3}}^{-1})$$, which is $$(\frac{1}{5} + \frac{1}{10} + \frac{1}{15})^{-1} = 2.73 \Omega$$. We can then rewrite this as a singular resistor with resistance $$ R_{eq} $$. 

## Equivalent Resistance Example
Let's do a more complex example now.

![R_complexcircuit](/assets/images/bpp7.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

![R_complexcircuit](/assets/images/bpp8.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

We first identify all the nodes (above image).

Now, let's start at point a. There is one path with the 10 $$\Omega$$ resistor that takes us to node 1. From node 1, there is one path to node 2 through 6 $$\Omega$$ resistor. There's also a path to node 3 and 4, but we will come back to that in a moment. Then, there are 2 paths from node 2 to node 3, through the 15 $$\Omega$$ and 60 $$\Omega$$ resistors. There is the 6 $$\Omega$$ resistor path from node 3 to node 4. After node 4, there is a 5 $$\Omega$$ path to point b. Now going back to node 1, we saw that there was a path to node 3 through 9 $$\Omega$$ resistor and a path to node 4 through 24 $$\Omega$$ resistor, so we will note that as well. 

![R_complexcircuit](/assets/images/bpp9.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

I don't want to redraw the circuit for each resistor simplification, so just try to follow along as close as you can. 

1. 15 $$\Omega$$ and 60 $$\Omega$$ are in parallel, so that resistance between nodes 2 and 3 can be simplified as $$ (\frac{1}{15} + \frac{1}{60})^{-1} = 12 \Omega$$. 

2. 6 $$\Omega$$ and 12 $$\Omega$$ between nodes 1 and 3 are in series, so we can add them up to get 18 $$\Omega$$. 

3. This 18 $$\Omega$$ is in parallel with 9 $$\Omega$$ (still between nodes 1 and 3), so we take the inverse of the added reciprocals to get 6 $$\Omega$$. 

4. Now, there is a singular 6 $$\Omega$$ resistor between 1 and 3 and a 6 $$\Omega$$ between 3 and 4. These two are in series, so we can add them to get 12 $$\Omega$$ between 1 and 4. 

5. There is 24 $$\Omega$$ in parallel with this 12 $$\Omega$$, which can be simplified as $$ (\frac{1}{24} + \frac{1}{12})^{-1} = 8 \Omega$$ 

6. We finally have a 8 $$\Omega$$ between nodes 1 and 4 along with 10 $$\Omega$$ after point a and 5 $$\Omega$$ before point b. These are in series, so we add them up to get 10 + 8 + 5 = 23 $$\Omega$$.
