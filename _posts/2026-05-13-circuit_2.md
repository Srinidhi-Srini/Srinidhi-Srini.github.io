## Kirchhoff's Current Law (KCL)

Kirchhoff's Current Law (KCL) states that the total current entering a node is equal to the total current leaving a node:

$$ \sum_{}^{} I_{in} = \sum_{}^{} I_{out} $$

![KCL circuit](/assets/images/bp9_2.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

For sign convention, we can say current entering the node is positive, and leaving the node is negative. 

### KCL Example
![KCL circuit example](/assets/images/bp9_1.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

First, it is given to us that $$i_{a} = 6 A$$ and $$ i_{c} = -2A $$. Let's identify all the nodes. We have 4 nodes, and at each of these nodes, we set the total current entering equal to the total current leaving. 

![KCL circuit example](/assets/images/bp9_3.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

1. Node 1: $$ i_{a} + i_{c} = i_{b} \rightarrow 6 + (-2) = i_{b} \rightarrow i_{b} = 4A $$
2. Node 2: $$ 0 = i_{c} + i_{d} \rightarrow 0 = -2 + i_{d} \rightarrow i_{d} = 2A $$
3. Node 3: $$ i_{b} + i_{d} + i_{e} = 0 \rightarrow 4 + 2 + i_{e} = 0 \rightarrow i_{e} = -6 A $$
4. Node 4: $$ 0 = i_{a} + i_{e} \rightarrow 0 = 6 + (-6) = 0 $$ 

We have successfully found all the unknown currents using Kirchhoff's Current Law. Next, let's look into Kirchhoff's Voltage Law.

## Kirchhoff's Voltage Law (KVL)
Kirchhoff's Voltage Law (KVL) states that the sum of voltages across a closed loop is equal to zero:

$$ \sum_{}^{} V = 0 $$

For sign convention, we can say that clockwise current is positive, and current always goes from high to low voltage. Additionally, we can say voltage that goes from negative terminal to positive terminal is negative, and vice versa. 

![KVL circuit](/assets/images/bp9_4.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

From Ohm's Law, we know that V=IR. Thus, even if we don't know the voltage or current across each resistor explicitly, we can write it as a product of current and resistance. When we are writing KVL for a loop, we can start at an element. I will start at the Voltage $$ V_{s}$$. When we go clockwise, the voltage goes from negative to positive, so its $$ -V_{s}$$. Then we go across the first resistor, positive to negative, so it's $$ + i_{1}R_{1}$$. Next, we go across the second resistor, positive to negative so it's $$ + i_{2}R_{2} $$. ## KVL Example

![KVL circuit example](/assets/images/bp9_6.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

First, it is given to us that $$ V_{a} = 5V$$, $$ V_{b} = 7V$$, $$V_{f} = -10V$$, and $$ V_{h} = 6V$$. Next, let us define the clockwise current to be positive and identify all the closed loops.

![KVL circuit example](/assets/images/bp9_7.png){: style="display: block; margin: 0 auto;"}
{: style="text-align: center;"}

1. Loop 1: $$ V_{b} + V_{a} - V_{d} = 0 \rightarrow 7 + 5 - V_{d} = 0 \rightarrow V_{d} = 12 V $$
2. Loop 2: $$ V_{d} + V_{f} - V_{g} = 0 \rightarrow 12 + (-10) - V_{g} = 0 \rightarrow V_{g} = 2 V $$
3. Loop 3: $$ -V_{e} + V_{g} + V_{h} = 0 \rightarrow -V_{e} + 2 + 6 = 0 \rightarrow V_{e} = 8 V $$ 
3. Loop 4: $$ V_{c} - V_{b} + V_{e} = 0 \rightarrow V_{c} - 7 + 8 = 0 \rightarrow V_{c} = -1 V $$ 

And thus, we have successfully found all the unknown voltages! In this particular example all the voltages were directly given to us so we can conceptually see how KVL works. In most examples, we don't know these voltages nor currents, (there might be some information given), so we will have to use a combination of KCL and KVL to solve the circuit unknowns.
